# Interview prep and job-search notes by Aiden Longoria

These are the notes I keep while preparing for entry-level software and cybersecurity interviews as a computer science student in Texas. They're written so someone who has never done a coding interview can follow them.

## Who this is for

- College students getting ready for their first technical interview or online assessment
- Entry-level job seekers who want a plain-language path through coding problems
- High school and technical-school students curious about what tech interviews ask

No prior interview experience is assumed. Every term is explained the first time it shows up.

## What's inside

| Folder | What it holds |
|---|---|
| `01 Fundamentals` | The basics: Big O notation, complexity, how to read a problem |
| `02 Patterns` | One note per problem-solving pattern (two pointers, hashing, sliding window, and more) |
| `03 Problems` | Worked problems, one note per problem per language (Python and C#), each with a trace table |
| `04 Roadmaps` | Suggested study order for Python and C# |
| `05 Interview Formats` | What entry-level assessments look like, and how to read code you've never seen |
| `06 Job Search` | Spotting fake postings, common knockouts, how long replies take, and my own numbers |

## How to use it

- **New to all of this?** Open [Start Here](Start%20Here.md) and follow it in order.
- **Reading on GitHub:** click through the folders; every note is plain Markdown.
- **Using Obsidian:** download or clone this repo and open the folder as a vault. Links between notes work out of the box.

Each problem note follows the same shape: what the problem asks, the pattern and the clue that points to it, a picture, questions to ask before coding, a trace table, the solution, its complexity, and the mistakes to watch for.

## A note on honesty

Assessment notes describe formats and lessons only. They never reproduce real assessment questions or name the companies behind them.

Problem notes marked **Worked example** are teaching walkthroughs for problems I'm still practicing, not my own solutions.
